## Key Rules

- Base package: `cl.gradeops.ai.agents` — do not change
- Agents generate and suggest; they never finalize scores, silently modify approved rubrics, or deliver output to students without teacher approval
- Closed-assessment grading (when implemented) is always deterministic — AI agents generate/analyze, never score
- No other module in `api/` may call Gemini directly — all agent invocation goes through `agents/` via the `agentclient` module in `api/`
- Prompts are per-agent, versioned files under `src/main/resources/prompts/` (`.st` StringTemplate) — content changes are prompt-versioning changes, not code changes
