## Key Rules

- Package name: `grade-ops-web` — do not change
- Student access uses signed token links (`AssessmentInvitation`) — no student login exists or should be built
- Gemini/Groq API keys are server-side only (inside `agents/`) — `web/` never touches them, directly or via env var
- Every AI-generated output affecting grading, feedback, or student-facing content requires an explicit `ApprovalEvent` before `web/` may present it as final — UI must reflect draft/pending vs. approved state distinctly
- Related-party revenue and pilot-flag UI (if applicable to a given screen) must surface `related_party`/`plan_type` flags per this project's evidence-reporting requirements
